# Android Shop App

Это высокопроизводительное, масштабируемое и модульное приложение для Android Shop, созданное с использованием современных технологий.

## 🚀 Технологический стек
- **Язык**: Kotlin
- **UI-фреймворк**: Jetpack Compose
- **Дизайн-система**: Material 3
- **Архитектура**: MVVM + Clean Architecture (модульная)
- **Внедрение зависимостей**: Hilt
- **Сеть**: Retrofit + OkHttp
- **База данных**: Room
- **Загрузка изображений**: Coil
- **Асинхронность**: Coroutines + Flow

## 🏗 Архитектура
Приложение следует принципам **Clean Architecture** для обеспечения разделения ответственности и тестируемости.

### Модули
- `:app`: Основная точка входа, навигация, настройка Hilt.
- `:core`: Общие UI-компоненты, тема и утилиты.
- `:domain`: Бизнес-логика, сущности и интерфейсы репозиториев.
- `:data`: Реализация репозиториев, база данных и сетевые сервисы.
- `:feature:*`: Независимые функциональные модули (Каталог, Корзина, Авторизация, Профиль).

## 📦 Особенности
- [x] **Каталог товаров**: Виды «список» и «сетка» с эффектом загрузки Shimmer.
- [x] **Корзина**: Обновления в реальном времени с использованием Room.
- [x] **Современный UI**: Полная поддержка Material 3 с темным и светлым режимами.
- [x] **Чистый код**: Принципы SOLID и структура, готовая к продакшну.

## 🛠 Установка и запуск
1. Клонируйте репозиторий.
2. Откройте в Android Studio (Iguana или новее).
3. Синхронизируйте Gradle и соберите проект.
4. Запустите на эмуляторе или реальном устройстве.
